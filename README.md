# Crack the Whip — NeoForge 1.21.1

## Сборка
Нужна Java 21 (JDK).
```
./gradlew build          # Windows: gradlew.bat build
```
Готовый мод: `build/libs/crackthewhip-1.0.0.jar` → в папку `mods`.
Запустить игру прямо из проекта: `./gradlew runClient`.
Открыть в IntelliJ IDEA: File → Open → папка проекта (Gradle подтянется сам).

Если Gradle ругается на версию NeoForge/плагина — поменяй `neo_version` в `gradle.properties`
на актуальную 21.1.x (https://projects.neoforged.net/neoforged/neoforge) и версию
`net.neoforged.moddev` в `build.gradle` (https://projects.neoforged.net/neoforged/moddevgradle).

## Хлыст Агонии
- 2 урона (1 сердце), медленный замах, +2.5 блока дальности удара, 640 прочности.
- **ЛКМ** — удар + Агония. Каждый удар повышает уровень (до V) и продлевает эффект (6–14 сек).
- **ПКМ** — щелчок на 7 блоков: бьёт первую цель на линии, подтягивает её к тебе (КД 1.2 с).
- Зачаровывается: прочность, починка, острота, заговор огня, отдача и т.д.
- Звук — твой `crack_the_whip` (сконвертирован в моно OGG, чтобы звучал в пространстве).

Крафт:
```
 . . К
 . К Н      К — кожа, Н — нить, П — палка
 П . .
```

## Эффект «Агония»
| | |
|---|---|
| Пульс боли | урон сквозь броню каждые 2.0 → 0.6 сек (растёт с уровнем). **Не убивает** — оставляет 1 HP |
| Скованность | −15% скорости и −10% урона атак за уровень |
| Уязвимость | +15% любого входящего урона за уровень |
| Незаживающие раны | любое лечение (регенерация, еда, зелья) заблокировано |
| Судороги | тело дёргает в случайную сторону; у игрока резко дёргает камеру |
| Изнеможение | с Агонии III нельзя бежать |
| Сердцебиение | стук сердца варда в такт боли, кровавые частицы, красная пульсирующая виньетка на экране |

Комбо: хлыстом довести до Агонии V (+75% урона), потом добить мечом.

## Кандальная цепь
Неразрушимая: не рвётся от расстояния, урона или смерти. Работает на **любом** мобе и на **игроках**.

| Действие | Что происходит |
|---|---|
| ПКМ цепью по мобу/игроку | заковать, конец цепи у тебя в руке |
| ПКМ цепью по любому блоку | приковать к блоку всех, кого ведёшь (к стене, столбу, полу…) |
| ПКМ пустой рукой по этому блоку | снять всех пленников с блока и снова вести их |
| ПКМ пустой рукой по прикованному | забрать конкретного пленника себе |
| Shift + ПКМ пустой рукой по пленнику | расковать, цепь выпадает (свой пленник или прикованный к блоку) |

- Длина цепи 6 блоков, дальше тянет. Унесло дальше 24 блоков (жемчуг, /tp, смерть) — цепь возвращает назад.
- Закованный игрок остаётся в цепях даже после смерти и перезахода.
- Моб в цепях не деспавнится; при смерти моба цепь выпадает.
- Если блок-якорь сломать — цепь падает на землю (как предмет).
- Нельзя заковать того, кто держит на цепи тебя.

Крафт (×2):
```
 . Ц .
 Ц Ж Ц      Ц — цепь (ванильный блок), Ж — железный слиток
 . Ц .
```
